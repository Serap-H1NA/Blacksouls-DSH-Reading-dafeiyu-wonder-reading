# 大肥鱼的不思议阅读

左侧栏一个羽毛入口，点开是阅读记录；另有一个置顶小条贴在游戏窗口旁边，随手按。

## 它做什么

1. **读状态，不读画面。** 游戏里的桥接器每 6 帧写一份 `state-*.json`，里面场景、地图、台词，以及 **说话人**（从游戏的名字窗读出来的）。插件按文件名顺序补读，一句不漏。
2. **一段一段记。** 台词清空、换地图、游戏停住、或单段超过 40 句就封口，写进 `dialogue.md`（人读）和 `dialogue.jsonl`（机读）。说话人挂在每一句上；同一句话两个人说，两句都留着。
3. **按需交给我。** 三个按钮都要人按，不按一分钱不花：
   - **阅读文字喵~(●'◡'●)**：把没读过的记录交给我读。输入框里写了话，就只按那句话回应；留空就按平时的样子讲理解。
   - **欣赏插图ο(=•ω＜=)ρ⌒☆**：截一张游戏窗口（被挡住也能截，最小化不行），和图一起交给我。
   - **生成阅读报告☆*: .｡. o(≧▽≦)o .｡.:*☆**：让我把这段读写成一份报告，存到你设置的目录。
4. **游戏里按 F9** 等于按「阅读文字」（需要重启一次游戏才会生效）。

## 悬浮窗

- 无边框、置顶，自动吸附在游戏窗口右边，游戏挪它跟着挪；
- 一行状态（记录中 / 地图 / 待发几段），一行最近一句（带说话人）；
- 五个按钮：阅读文字、欣赏插图、生成阅读报告、收成小圆点、退出；
- 随 DSH 启动；DSH 关掉后它自己退出（收不到心跳就退）。

## 面板（左侧栏点开）

- 一句话状态、最近的记录（带说话人名牌）、一个输入框和三个按钮；
- 「设置」里：阅读报告存放位置、自动阅读开关、悬浮窗随 DSH 启动、**清除阅读历史**（先备份 .bak 再清空，有确认窗口）。

## 配置（`cordis.patch.yml` 里改）

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `gameDir` | `<你的游戏目录>` | 游戏副本目录 |
| `dataDir` | `…/default-workspace/阅读记录` | 记录写到哪里 |
| `reportDir` | 空 | 阅读报告目录；留空时按钮会提醒先设置 |
| `autoAnalyze` | `false` | 每段是否自动交给我（默认关） |
| `widgetAutoStart` | `true` | 随 DSH 启动悬浮窗 |
| `pollMs` / `staleMs` / `idleCloseMs` | 250 / 5000 / 2000 | 轮询与封口的时间参数 |
| `maxLinesPerBlock` | 40 | 单段最多几句 |

## 限制

- 需要装好桥接器的副本（`Data/Scripts.rvdata2` 已注入，且含 F9 钩子）。
- 游戏窗口最小化或被挂起时桥接器停写，面板显示「游戏未运行」；截图也会失败。
- 说话人来自游戏的名字窗；旁白没有名字，不会瞎猜。
- 悬浮窗需要系统里有 `pythonw`（Python 3 自带）；没有就只用手动方式。
